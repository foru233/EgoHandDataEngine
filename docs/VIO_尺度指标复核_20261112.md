# VIO 地图几何指标复核（2026-11-12）

## 更正结论

此前“共同点相对均值质心的半径P50增长”不能单独证明整张地图等比例放大。少量极远点会移动均值质心，使其余正常点的半径一起变大。原始报告和预先定义的指标保留，本次新增诊断不追溯替换主指标，也不据此发布显著性结论。

`tests/test_vio_map_geometry_audit.py`用200个正常点、只移动其中1个点即可复现：质心半径P50增长超过20倍，而共同点对距离的中位比值仍为1。另一个测试验证真实3倍缩放会被成对距离检出，且不受整体旋转/平移影响。

## 对后续工作的影响

- 正式噪声密度保持原值。2×2单轮探索中的Python辅助源码发生变化，严格四组对照不成立，保留全部执行记录，不作为改默认参数的依据。
