| 结论 | 外参已不是当前瓶颈（2×2 A/B 显示两版差异被运行间方差淹没） |

### 1.2 跳变根因（已取证并修复主机制）

**根因**：`FullInertialBA(bFixLocal=false)` 缺少世界平移 + 重力轴 yaw 约束，整图可沿零空间漂移。

三路独立证据：

1. **视觉侧排除**：所需画内位移 / 实测 = 18–3195×；视差前后不变（10.00 px → 10.00 px）
2. **原生形态**：75 个关键帧等量平移 22.82 m，方向 cos **0.99999**，扣除均值后残差仅 1.4%；对照健康求解 cos 0.279
3. **代价函数分解**：EdgeStereo chi2 1.446→1.307（几乎不变）、**EdgeInertial 2179.9→0.366** → 该平移落在零空间

**修复**：`EdgeWorldGauge`（实验 C）使关键帧位移 **22.82 m → 0.038 m**，方向一致性 0.99999 → 0.341。

### 1.3 已修复的独立缺陷

| 缺陷 | 修复 | 验证 |
| --- | --- | --- |
| **VIBA2 初始化 NaN 猝死**（`0xC0000409`，概率性） | `VioSafeExp.h` 拦截 `SO3::exp` 的 NaN/inf | 12/12 单测；1727 帧回放 `error=null`、Sophus 报错 0 |
| **`map_epoch` 漏计整图重锚** | 原生 `world_frame_revision`（SE(3) 拟合判据） | 第 964/976 行检出，`map_epoch` 均为 8 未变 |

### 1.4 地图点深度发散（未根治，但方向已明确）

**现象**：地图点被推到公里级（event6 p95 2554 m、max 4052 m），跨事件累积（求解前 max 27 → 328 → 472 m）。

**机制**：远点 + 深度方向信息近似奇异 + BA 沿视线推远并累积。

| 尝试 | 结果 |
| --- | --- |
| 三角化门限分析 | 判据 `cos(2·atan2(mb/2, depth))` 随深度→1，**越远越宽松**（代码级） |
| `System.thFarPoints`（6.5 m） | **否定**：只拦新建点，仍被拉爆 |
| 条件数诊断 | **非独立根因**：cond 高 53×/487×，但 AUC 与"点到原点距离"几乎等同（0.988 vs 0.994） |
| 绝对深度门限（100×基线） | **机制可信、效果未证**：拦截量随倍率单调（50×≈4000 / 100×≈830 / 200×≈109），远点中位 965→98；但用的是后来被证明不可靠的 `>50 m` 计数，且对照仅 5 次 |
| BA 后止血 v2（位移阈值） | **否定**：位移阈值对 100 m 的点几乎无约束（5% = 5 m） |
| BA 后止血 v3（深度倍数） | **未证明有效（已更正）**：n=4 对照时看似"14/14 优于对照中位"，补到 n=10 后对照中位从 86.4× 降到 **39.0×**，置换 p=0.427、Fisher p=0.758，剂量-反应不成立（3.0 档 43.9× 高于对照），且门控后有效位姿 −7% |

**当前认识**：入口门限管"产生"（机制可信）、BA 侧"放大"仍未解决。**事后删点方案（止血）已被证明无显著收益且有代价**，不应启用。

**⚠️ 指标与样本教训**：`>50 m` 计数在某些运行里等于事件总数（整图被放大），不可靠；对照组 n<10 时的"整齐结论"（如"全部优于对照中位"）不可信 —— 本项目已两次踩此坑（实验 C 的 n=2、止血的 n=4）。

### 1.4.1 关键补充：踩到了指标陷阱，已建立正确指标

此前所有远点对照都用 `>50 m` 点数作主指标，但它**在某些运行里等于事件 6 的总点数**，无法区分两种本质不同的情况：(a) 剩少量远点；(b) 整张图尺度被放大。

已实现 `scripts/analyze_map_scale.py`（`spread` 用**质心**，对整图平移不变），10 次运行的结果彻底澄清了这一点：

| 指标 | 结果 |
| --- | --- |
| 关键帧 spread p50（所有运行、所有事件） | **0.059–0.252 m**（桌面尺度，始终正常） |
| event2 点 spread 放大倍数 | 0.82–1.17×（几乎不变） |
| **event6 点 spread 放大倍数** | **5.56–145.83×**（中位 OFF 77.6× / ON 39.1×） |

→ **不是"整图被放大"，而是"地图点相对关键帧被拉爆"**：位姿正常、点云崩坏。这把根因收窄为：
**远点的深度方向几乎没有约束力，BA 可把点推到任意远，而关键帧位姿不受影响。**

详见 `docs/整图尺度指标_20261111.md`。

## 三、关键教训（写下来避免重复踩）

1. **先建可观测性，再改行为**。前三次对照（thFarPoints / 止血 / 门限首次）全部因"无法确认机制是否生效"而无效。
2. **单次对照会被方差淹没**。同配置重复跑，同段 >0.5 m 次数可从 5 变到 49；实验 C 在 n=2 时"有效"、n=5 时"无效"。
3. **指标要选对**。"同段 >0.5 m 次数"混入跟踪丢失/重调度抖动；衡量重锚应用 `world_frame_revision`，衡量远点应用 `>50 m` 点数。
4. **ABI 改动要加字段到末尾或用独立导出**。中途插字段会让既有 DLL 报尺寸不匹配（`EgohandVioWorldFrameInfo` 保持 144）。
5. **我犯过并已更正的判断**：n=5 "实验 C 无效"（指标选错）、"畸变由 BA 自身产生"（实为放大三角化远点）、"条件数不足以解释"（半成品数据）。
