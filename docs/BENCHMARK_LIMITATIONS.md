- **真实端到端三维未验收**：三个HOT3D Aria训练片段450帧，官方正向原生灰度推理没有同帧双路同时检测；有效三维0，MPJPE=N/A。重采样管线也没有有效输出。已有真值不意味着模型能在该输入域可靠运行，不能宣称HOT3D精度达标。
- **STB BLOCKED_BY_DATA**：当前官方OneDrive失效、百度链接失效、历史Dropbox未能列出可验证数据。适配器/映射/门禁有测试，真实资产测试跳过，不是数据集成绩。还需要完整标定/图像几何与GT坐标证据。
- **003365 GT保留**：官方test_aria，无hands.json。只报告检测与关联行为；不从其它片段借用姿态/手形造GT。
- **UmeTrack与MANO**：已经用官方UmeTrack FK导出canonical20世界点；未实现或验收MANO路径，未获取/接受额外MANO资产许可。20点是模型语义对应，仍可能存在模型间定位/手形差异；MediaPipe thumb CMC排除。
- **相机/图像**：FISHEYE624使用官方模型，标定按帧更新。640×480/f160的公共虚拟视图是固定几何选择，并非无损全部视域；黑区/重采样/小手尺寸降低检测。native路径可避免先重采样检测，但不能解决遮挡和原生模型域偏移。只测Aria，Quest3解析尚无真实执行证据。
- **同步**：原生ns字段和DATASET_DOCUMENTED不等于硬件验收。GT ref时间与每路图像有偏移；没有实测曝光中心/滚动快门误差，不具备本机硬件同步能力证明。
- **不确定性**：固定虚拟/校正后像素std未校准，不含标定、时序、系统偏差、多模态遮挡及身份错误；native像素到虚拟像素的噪声不是完整传播链。拒绝阈值未经过真实有效预测分布验证，保持诊断默认。
- **身份**：更保守的长间隔恢复需要至少两次运动历史、预测和中心化姿态吻合，但仍不是人的身份概率。对极近、同形、完全遮挡的双手，允许拒绝/新建track，无法承诺连续ID。官方2D投影用于评测身份也有限制；未知对不算已正确匹配。
- **覆盖场景**：尝试三个训练片段和一个测试片段，包含双手/物体操作、视野边缘、建模遮挡、两视图漏检。不能证明八类困难场景均有人工认证覆盖。快速运动/同深度交叉另有明确合成对抗测试，不能替代真实场景精度。
