# 深度倍数止血：对照组补到 n=10 后的结论更正（2026-11-11）

> **本文推翻 `docs/深度倍数止血_倍率扫描_20261111.md` 第 2 节的"14/14 全部优于对照中位"。**
> 那份结论建立在只有 4 次对照运行的基础上，而对照组的运行间方差极大。

---

## 1. 发生了什么

上一轮对照只有 4 次（`off_run1..4`），中位 **86.4×**，且 range 16–161。三档比例共 14 次运行全部低于这个中位，看起来是强信号。

补跑 6 次对照（`off_run5..10`）后：

| 臂 | n | event6 放大倍数（各次） | 中位 | 范围 |
| --- | ---: | --- | ---: | --- |
| **OFF（对照）** | **10** | 161 / 125 / 51 / 48 / 46 / 32 / 22 / 16 / 8 / **3** | **39.0×** | **2.9 – 161.5** |
| ratio 2.0（处理） | 5 | 62 / 27 / 26 / 25 / 22 | **26.3×** | 21.6 – 61.8 |

**对照中位从 86.4× 掉到 39.0×**，且出现了 2.9×、8×、16× 这样的低值 —— 说明对照组本来就能"偶尔很好"，之前 4 次恰好没有抽到这些。

## 2. 检验结果（全部不显著）

| 检验 | 结果 |
| --- | --- |
| 中位数精确置换检验 | p = **0.427** |
| >50× 二分类 Fisher 精确检验 | OFF 3/10 vs ON 1/5，p = **0.758** |
| "ON 全部低于 OFF 中位" | **False**（ON 的 62× 高于对照中位 39×） |

## 3. 剂量-反应关系也变弱了

| 组 | 中位放大倍数 | 与对照中位（39.0×）比较 |
| --- | ---: | --- |
| OFF | 39.0× | — |
| ratio 1.5 | 17.9× | 更低 ✔ |
| ratio 2.0 | 26.3× | 更低 ✔ |
| **ratio 3.0** | **43.9×** | **更高 ✘** |

最松的一档（3.0）反而**高于**对照中位，这与"越严越好"的单调关系矛盾。因此上一轮说的"剂量-反应关系清晰"**不成立**。

## 4. 结论（更正后）

| 项 | 更正后的结论 |
| --- | --- |
| 机制是否生效 | **是**（计数器：OFF 全 0、ON 中位 1335，已确证） |
| 是否降低点云放大倍数 | **无法证明**（p=0.43–0.76，区间完全重叠） |
| 剂量-反应关系 | **不成立**（3.0 档高于对照中位） |
| 代价 | 门控后有效位姿 −7%（ratio 2.0）确实存在 |
| 是否可上线 | **否** |

**净判断：深度倍数止血在这组数据上既不显著、又有明确代价，不应启用。**

## 5. 这次的教训（已加入检查清单）

1. **对照组的样本必须与处理组同量级**，且要先看对照组的分布宽度。4 次对照无法代表一个 range 达到 2.9–161× 的分布。
2. **"全部低于对照中位"这类整齐结论，要先怀疑对照样本太小**。这是本项目第二次遇到同样问题（第一次是实验 C 的 n=2）。
3. 任何"剂量-反应"的说法必须**包含最松的那一档**，否则容易只看到支持假设的两档。
4. 我第一版 Fisher 检验公式也写错过（把处理组未发生数当总体未发生数，得出 p=0.0000），已单独记录。

## 6. 对整体结论的影响

**不受影响**（这些仍成立）：

- 跳变根因（`FullInertialBA` 零空间整图平移）与 `EdgeWorldGauge` 修复（22.82 m → 0.038 m）
- `world_frame_revision`（ABI 安全、回放检出 36 m 重锚）
- VIBA2 NaN 猝死修复（12/12 单测 + 1727 帧）
- 可观测性链路（`optimization_counters`）
- 整图尺度指标（关键帧 spread 0.059–0.252 m 始终正常，点云 spread 5.6–161× 崩坏）

**受影响（需要降级）**：

- 深度倍数止血：从"方向明确、有剂量关系"降为"**未证明有效**"
- 远点门限 100× 的"远点中位 965→98"也应重新审视——它同样只有 5 次对照，且用的是后来被证明不可靠的 `>50 m` 计数

## 7. 建议

1. **不要在实机启用任何门限/止血开关**，直到用统一的、n≥10 的对照流程重做；
2. 若还要继续，应先把"对照组基线分布"测清楚（同一配置跑 10–20 次，报中位 + IQR + 极值），再谈处理效果；
3. 更值得投入的仍是**机制层面**：给远点的深度方向在求解图里加真约束（而不是事后删点），这样效果不受运行间调度方差影响。
