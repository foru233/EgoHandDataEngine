# 自适应工作台界面更新

2026-11-03。已安装并实际使用 UI/UX Pro Max；采用适合桌面科学工具的简洁风格及其对比度、分组、焦点、空状态规范。具体筛选过程和设计契约见 `design-system/egohand-studio/MASTER.md`。

## 对用户反馈的落实

1. 四项指标由大卡片变为约38px高的一行，说明放入悬浮提示和诊断页。
2. 相机/三维区域使用剩余窗口空间。自动布局按图像比例和可用高宽选择左右或上下排列，避免只给相机160px高度。
3. 左右图像保持完整等比显示，不拉伸、不静默裁剪。画面视框接近原图比例，显著减少两侧空白。
4. 起始窗口大小读取当前屏幕的可用区域；用户调整窗口时重新分配视框尺寸。
5. 配置面板可以收起；三维视图的布局下拉框可以手动选择“自动布局 / 双目在左 / 双目在上”。
6. 操作、诊断、左右手坐标分组，原始算法、数据来源及真实性门控保持原有契约。

## 连续拖动跳变修复

后续复现了三维鼠标交互问题：拾取时 PySide6 的矩阵/向量 `*` 运算报错，可能跳过新按下事件的起点初始化；坐标栏的长文本还会引起视框重新布局，旧逻辑把局部坐标变化当成鼠标移动。
现改为每次按下建立独立屏幕坐标锚点、按真实光标增量委托 PyQtGraph 旋转/平移、松开/失焦/取消抓取时清除状态。关节拾取改到单击松开，使用显式浮点向量和 `matrix.map()`，拖动不触发选取；坐标栏固定尺寸策略，完整内容保留在悬浮提示。
新增 `tests/test_skeleton_interaction.py` 的9项回归，覆盖非空骨架上的不同起点连续拖动、旋转/中键/控制键平移、视框移动、松手残留、失焦、单击选取与坐标栏布局。当前全工程85项通过，证据 `logs/drag_fix_full.xml`。运行中的旧进程需重启后加载修复。
