# HOT3D 直接打开与回放

启动 `run_gui.bat` 或 `run_gui.py`，上方数据源选择 **HOT3D Clips**。

1. 点“打开数据”，选择 `samples/date/hot3d/train_aria/clip-001849.tar`。也可在右侧“采集”中点“选择 HOT3D 目录”，选择整个数据目录、train_aria 或已解包片段。
2. 点“开始回放”。默认“官方真值（GT）”，显示双灰度图及官方 UmeTrack canonical20 三维点，每手20点，CMC不补齐。顶部、三维标签与坐标面板明确标注官方真值。
3. 暂停后可“单帧”，或在底部输入全局帧索引点“定位”。一个片段150帧；多片段根目录连续排列。
4. 右侧“采集”切换“算法预测（MediaPipe）”，后台加载官方模型，在当前帧暂停；点击暂停/继续按钮恢复连续播放。此路径先用官方 FISHEYE624 生成虚拟双目校正图，再在校正图上检测关键点，GT不进入重建算法。切回GT不把预测补成真值。
5. 可录制当前运行，保留原来的原生录制结构。之后用“导入结果”选新录制目录即可回放，不重新推理。用“录制/外部清单”重新处理HOT3D录制时默认运行预测。

## 数据与限制

001849、001851、001894有已核验的官方UmeTrack缓存；003365实际上为测试集，GT模式显示不可用和空三维，仍可查看图像/切换预测。预测在这些灰度片段上可能没有有效三维输出，这不是导入失败，不用GT代替预测。

选择已有解包目录且存在同名tar时优先读取已验证原包；缺tar的纯解包目录支持图像/预测，无法验证缓存对应关系时不显示GT。未知/损坏官方tar哈希明确报错。新片段若没有官方FK缓存，需先使用prepare_hot3d.py在独立Torch环境转换；GUI不自动安装或执行MANO。

只读取1201-1和1201-2；RGB214-1不作为双目。原生逐帧FISHEYE624、时间戳、GT来源保存在raw元数据，GUI显示官方模型生成的公共虚拟校正视图（黑区和有限公共视域保留）；三维坐标回原始1201-1光学坐标。DATASET_DOCUMENTED不代表本机硬件同步验收。

界面沿用现有布局/主题，首次有有效HOT3D三维时适配镜头位置；后续帧不重置用户拖动视角，重置按钮重新适配。修复暂停期间定位请求被读取线程吞掉的竞争问题。

## 验证

`tests/test_hot3d_gui.py` 验证实际tar、目录入口、真值/预测隔离、缺GT、定位、模式切换、录制结果再次导入。完整测试XML为 `logs/hot3d_gui_final_tests.xml`。原生Qt验证脚本 `scripts/verify_hot3d_gui.py` 已在四尺寸、深浅主题下截图，GL有效、40点GT，实际预测输出0点、测试GT不可用。截图和源码修改前快照在 `logs/hot3d_gui_20261103_140745`。

旧录制和现有算法接口保留。未实现HOT3D格式导出、MANO评测或新的手部检测网络。
