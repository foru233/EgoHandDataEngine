# 深度倍数止血（v3）：5×2 对照结果（2026-11-11）

配套：`docs/整图尺度指标_20261111.md`（指标）、`docs/地图点止血_5x2结果_20261111.md`（v2 位移判据，失败）

---

## 1. 为什么改判据

v2 用**位移阈值** `max(1 m, 5%·|p|)`：对 100 m 的点，5% 就是 5 m，**几乎等于没约束**，所以 5×2 无效果。

根因分析（`EdgeStereo`）：`_error = obs − ProjectStereo(point)`，第三维是 `u_r = u_l − bf/z`，**对深度的雅可比随 1/z² 衰减**，深度大时信息矩阵近乎奇异（实测 `sigma_min` 1e-5）。

因此改用**深度倍数**判据，直接针对该衰减：

```cpp
const float bound = pMP->GetMaxDistanceInvariance();   // = 1.2 × mfMaxDistance
const float range = (vPoint->estimate() - pRef->GetCameraCenter()).norm();
if (range > bound * PointClampDepthRatio())  →  SetBadFlag
```

- `mfMaxDistance` = 参考关键帧观测深度 × levelScaleFactor，天然是"合理上界"；
- 默认倍数 **2.0**（`EGOHAND_VIO_POINT_CLAMP_DEPTH_RATIO`）；
- 保留原位移判据作为第二判据（同一开关，任一命中即丢弃）。

开关仍是 `EGOHAND_VIO_POINT_CLAMP=1`，默认关闭。

## 2. 结果（1200 帧 × 5×2）

### 2.1 机制确认生效

| 臂 | 丢弃计数 |
| --- | --- |
| OFF（5 次） | 0, 0, 0, 0, 0 |
| ON（5 次） | 1335 / 1331 / 1362 / 1047 / 1911（中位 **1335**） |

对比 v2（位移判据）中位 567，**深度判据多拦了约 2.4 倍** —— 符合"位移阈值对远点无效"的判断。

### 2.2 主指标（整图尺度指标，`docs/整图尺度指标_20261111.md`）

| 臂 | event6 点 spread 放大倍数 | 中位 | 范围 |
| --- | --- | ---: | --- |
| OFF (n=4) | 161.5 / 125.2 / 47.5 / 16.1 | **86.4×** | 16.1 – 161.5 |
| ON (n=5) | 61.8 / 27.3 / 26.3 / 25.4 / 21.6 | **26.3×** | **21.6 – 61.8** |

- **中位从 86.4× 降到 26.3×（降低 3.3 倍）**
- **ON 的 5 次全部低于 OFF 的中位**（86.4×）
- 但**区间仍有重叠**：OFF 最好一次 16.1× 低于 ON 最差一次 61.8×

### 2.3 统计检验

- 单侧**精确置换检验**（枚举全部 126 种分组）：**p = 0.357**
- 结论：**样本量不足（4 vs 5）、区间重叠，因此不能宣称统计显著。**

## 3. 安全指标

| 指标 | OFF 中位 | ON 中位 | 变化 |
| --- | ---: | ---: | --- |
| 原生有效位姿 | 1107 | 1093 | −1.3% |
| 门控后有效位姿 | 469 | 435 | **−7%** |

门控后有效位姿下降 7%，在可接受范围，但**需要关注**：丢弃 1000–1900 个点后跟踪质量略有下降。

## 4. 结论（诚实版）

| 项 | 结论 |
| --- | --- |
| 机制 | 已确认生效，且比位移判据敏感 2.4 倍 |
| 主指标方向 | **明确改善**（中位 86.4× → 26.3×，3.3 倍） |
| 一致性 | ON 全部低于 OFF 中位，但区间重叠 |
| 统计显著性 | **不显著**（p = 0.357，n=4 vs 5） |
| 代价 | 门控后有效位姿 −7% |
| 建议 | **方向值得继续**，但不能作为"已修复"上线；需 n≥10 或扫倍数 1.5/2/3 |

## 5. 为什么这个结果比前几轮可信

1. 用的是**对整图平移不变的指标**（spread 用质心），不会被 22.82 m 那种重锚污染；
2. 有**计数器**证明机制生效（OFF 全 0、ON 中位 1335）；
3. 判据有**明确的物理依据**（`EdgeStereo` 的 1/z² 雅可比衰减 + `mfMaxDistance` 语义）；
4. 做了**精确置换检验**而不是只看中位数。

## 6. 下一步

1. **补样本**：每组 ≥10 次，或用 1.5/2.0/3.0 三档倍数各 5 次；
2. **注意 −7% 的门控后有效位姿**：若放大倍数，跟踪可能进一步下降，需要权衡；
3. 若确认有效，可考虑改成"降低这些点的信息权重"而非丢弃（避免丢点导致的跟踪退化）。
