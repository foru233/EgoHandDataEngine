> 完整结论见 `docs/地图点条件数诊断_20261111.md`（由补诊断的子任务用 1244 点、before/solved 两阶段、含 AUC 判别力分析得出）。

## 1. 这次做了什么

给原生诊断加了一个**每点 3×3 信息矩阵条件数**（`*_point_condition.csv`，列：`id,observations,edges,sigma_min,sigma_max,condition_number,trace,valid`），用来把"远点的深度方向信息接近奇异"从推论升级为实测。

## 2. 更正：条件数确实显著更高，但不是独立根因

**初稿的错误**：我当时只拿到一次崩溃运行（984 帧 abort）的 `fullba_before` 数据，883 个点里 p50 只有 67、仅 9 个点病态，于是写了"条件数不足以解释大部分发散"。**这个判断基于不完整数据，已作废。**

完整数据（1244 点，before 与 solved 两阶段，分组已扣除整图刚体平移）：

| 组 | n | cond 中位（before） | cond 中位（solved） | sigma_min 中位（before） |
| --- | ---: | ---: | ---: | ---: |
| 稳定 <1 m | 1040 | **62.6** | 63.2 | 2.97 |
| 中 1–100 m | 97 | 70.8 | 114.4 | 0.880 |
| **发散 >100 m** | 107 | **3318** | **30 770** | **9.63e-04** |

**条件数确实高 53×（before）/ 487×（solved）**，判别力 AUC 达 **0.988 / 0.999**。

**但**：`AUC(点到原点半径) = 0.994`，与条件数几乎等同；`Spearman(log sigma_max, log radius) = -0.763`；把范围限制到 ≥50 m 的 101 个点内部，条件数与位移幅度的 Spearman 只有 **0.028**。

→ 条件数测到的主要是"**深度方向弱可观测性随距离恶化**"这一几何事实，**不是独立的数值根因**，也不能解释"1 km vs 3 km"的幅度差异。

## 3. 卡住初稿的那个崩溃

该次回放在 **984 帧崩溃**（`worker_exit_code = 3221226505` = `0xC0000409`）。崩溃日志：

```
start VIBA 2
Sophus ensure failed in function 'Sophus::SO3<float,0>::expAndTheta', line 617.
SO3::exp failed! omega: -nan(ind) -nan(ind) -nan(ind)
```

- 与 `PointInformationMetrics` **无关**（event6 的 before CSV 已成功写出）；
- 是 `Preintegrated::GetDeltaRotation` 把 NaN 传进 `Sophus::SO3f::exp`；
- **概率性触发**：同命令重跑即通过，另两个 DLL 同命令 1200 帧均 OK。

已针对该路径做加固：新增 `VioSafeExp.h`，`ImuTypes.cc:288/312` 改为 `NormalizeRotation(VioSafeExp(...))`，12 项单元测试全过（有限输入与 `SO3::exp` 一致、NaN/inf/超大值不抛异常并保留原旋转）。详见 `docs/地图点条件数诊断_20261111.md` 与后续提交。

## 4. 结论

1. **条件数分析已完成**，工具可用（`egohand_vio_point_cond.dll` + `scripts/analyze_vio_point_condition.py`）。
2. 它给出的定性结论是：**远点的深度方向弱可观测量随距离单调恶化**，与"远点 + 无深度约束"的几何成因一致，但**不构成独立根因**。
3. 真正的修复方向仍指向 `docs/地图点止血_设计方案_20261111.md`（BA 后扣除刚体变换的位移 outlier 止血）与"远点供给控制"。
