# 地图点位移止血：设计方案（2026-11-11）

## 1. 目标

阻断"远点被 `FullInertialBA` 沿深度方向推远 → 下一轮初值更差 → 跨事件累积"的链条。已实测的累积曲线（点云半径 max）：

| 事件 | 求解前 | 求解后 |
| --- | ---: | ---: |
| event1→2 | 27 m | 98 m |
| event3→4 | 328 m | 644 m |
| event5→6 | 472 m | 4052 m |

## 2. 为什么不能简单用"位移超阈就丢弃"

**合法的整图重锚会搬动所有点**（取证：event6 中 75 个关键帧等量平移 22.82 m、方向 cos 0.99999）。如果用"点位移 > 1 m 就丢弃"，重锚时会把整张图清空。

因此判据必须是**扣除整体刚体变换后的残差**：

```
p_before_world ──(拟合的整体 SE(3))──> p_predicted
residual = || p_solved - p_predicted ||
residual 超阈 → 判为异常点，不写回
```

这套整体 SE(3) 拟合**已经存在**：`third_party/ORB_SLAM3/include/VioWorldFrameRevision.h`（Umeyama 同 ID 关键帧拟合，纯 Eigen，已被 `FullInertialBA` 用于 `world_frame_revision` 判定）。

## 3. 插入点

`third_party/ORB_SLAM3/src/Optimizer.cc:869-889`（`FullInertialBA` 的点回写循环）：

```cpp
//Points
for(size_t i=0; i<vpMPs.size(); i++)
{
    if(vbNotIncludedMP[i]) continue;
    MapPoint* pMP = vpMPs[i];
    g2o::VertexSBAPointXYZ* vPoint = static_cast<g2o::VertexSBAPointXYZ*>(optimizer.vertex(pMP->mnId+iniMPid+1));
    if(nLoopId==0) {

        pMP->UpdateNormalAndDepth();
    } ...
}
```

**只在 `nLoopId==0` 分支加判据**（回环 GBA 走 `mPosGBA` 延迟应用路径，本轮不动）。

## 4. 判据与参数

| 项 | 取值 | 依据 |
| --- | --- | --- |
| 整体变换来源 | 同 ID 关键帧的 SE(3)（复用 `VioWorldFrameRevision`） | 已在用，避免重复实现 |
| 残差阈值 | `max(1.0 m, 5% × ||p_before||)` | 与现有重锚判据同量级（0.05 m/5% 用于关键帧，点用更宽松的 1 m 避免误杀） |
| 超阈动作 | **不写回**（保留旧位置）+ 计数 | 保守：宁可保留旧值，不新增畸变 |
| 开关 | 环境变量 `EGOHAND_VIO_POINT_CLAMP=1`（默认关） | 与仓库现有 experiment 开关风格一致（`EGOHAND_VIO_GAUGE_*`） |
| 输出 | 诊断模式写 `*_point_clamp.csv`（id, before, after, predicted, residual, clamped）与汇总计数 | 便于量化"拦了多少" |

## 5. 验证方法（必须做，否则不算完成）

1. **单元/几何测试**：给合成的"整体平移 + 局部畸变"点云，验证
   - 整体平移的点**全部保留**（不误杀）；
   - 只有局部畸变的点被拦；
   - 空集/退化点云不崩。
2. **真实回放对照**（同一录制、同一 DLL 构建、只切环境变量）：
   - 点云半径 max 在 event6 之后的累积曲线是否被压住（这是主指标）；
   - `world_frame_revision` 是否仍能正常检出重锚（不能被止血逻辑破坏）；
   - 位姿有效帧数不应显著下降（防止"止血"变成"砍地图"）。
3. **回归**：现有 29 项相关测试全绿；`world_frame_revision` 的 30 项原生测试不受影响。

## 6. 风险与回退

| 风险 | 处理 |
| --- | --- |
| 误杀合法点导致地图稀疏 | 默认关闭；阈值可调；对照运行看有效位姿数 |
| 与 `world_frame_revision` 的整体拟合冲突 | 复用同一拟合，不改其逻辑；止血只读拟合结果 |
| 与并行 agent 冲突 | **本方案暂缓实施**：`Optimizer.cc` 在 18:52 被 point_cond 子任务修改过，须等其完成并确认后才动手 |
