# 手动指定检测 ROI

重启程序，在右侧“检测”页找到“手动检测 ROI”（位于模型按钮下方）。支持左右视图分别设置，不增加主视图区或四项指标的占用。

1. 打开图像或回放；建议先暂停到目标帧。
2. 选择“左图”或“右图”，点击“在图上框选”，在对应图像内拖动。边框显示ROI；重新框选即可调整。
3. 也可以输入X、Y、宽、高（单位px），点击“应用坐标”。坐标原点为完整显示图左上角，框必须在图内且至少8×8px。全图ROI会归一为全图模式。
4. “当前全图”清除所选侧；“清除两侧”恢复左右全图检测。Esc/右键取消正在进行的框选，保留上一次区域。
5. 点击“保存配置”写入 `configs/roi.yaml`，下次启动载入。未保存的调整只保留在当前会话。切换数据源会按比例保留ROI，请确认仍适用或手动清除。

## 生效与坐标

- 应用后对应相机视图等比放大显示ROI，直到清除或重设；另一视图按自身ROI独立显示。点击重新框选时暂时恢复完整图，取消框选后恢复原放大视图。
- ROI针对**完整图像**，不包括保持比例显示时控件四周的留白。窗口缩放不改变ROI比例，也不拉伸图像；此显示裁剪不改变原始图像和三维坐标。
- 模型只收到所选裁剪；检测出的局部关键点加回裁剪偏移，归一化坐标/模型z尺度同步恢复。输出UV仍是完整图坐标，不把局部坐标直接交给三角化。
- ROI、检测输入和二维关键点均使用极线校正显示图的像素坐标。单图缺少有效双目标定时不运行检测。
- HOT3D 左右两路均使用官方 FISHEYE624 生成虚拟极线校正图，ROI 和检测均使用对应显示图。
- HOT3D正式三维结果仍按原坐标约定转回原生1201-1左光学坐标，单位米；ROI不改变内外参。
- 暂停时应用ROI会重算当前已处理的原始帧，保留未处理队列；继续/单帧/定位操作仍可用。没有双目标定的单图不能执行检测。
- 实时运行从后续处理帧生效，更新时重建检测器并重置跟踪会话，避免旧视频ROI/ID状态污染。
- 复用录制关键点的场景中，设了手动ROI的侧会真正重新运行模型，而不是沿用旧观测。
- 合成投影、官方GT模式及已有结果回放不因ROI变成模型预测；ROI仅对实际图像模型推理生效。框选不会保证遮挡手检出，也不会绕过三维质量门控。

## 配置与API

```yaml
# 完整检测输入图上的归一化 [x, y, width, height]；null表示全图
left: [0.25, 0.45, 0.45, 0.50]
right: null
```

独立检测器可用 `MediaPipeHandDetector(..., roi=(.25,.25,.5,.5))` 或 `set_roi(...)`，清除用 `set_roi(None)`。VIDEO更改ROI会重置视频实例，防止沿用旧裁剪跟踪状态。默认配置两侧均为null，旧流程保持。

配置不会自动应用到独立benchmark CLI；如需做ROI实验，须明确把同样的区域/图像坐标域传给对应检测器，并单独记录结果，不能与原全图基线混用。

诊断保存 manual_rois、applied_to_prediction、pixel_roi、模型输入域及有效检测参数；录制模型元数据保存起始ROI，运行中修改另外写roi_changed事件。ROI重算结果可复用同一原始帧时间，但使用重置后的处理session_id；不伪造新的传感器时间。

验证：字母边留白排除、窗口缩放、Esc取消、数字输入、左右独立/保存/清除、HOT3D坐标域、GT不调用模型、暂停应用/重算、单图重算、离线队列不丢帧及非法配置。原生深浅主题截图见 `logs/roi_implementation/roi_dark.png`、`roi_light.png`，测试XML同目录保存。
