# 修改前后

修改前，失跟帧只在状态栏显示“IMU 临时预测”，`update_live()` 随后调用 `set_pose_axes(None)`，相机轴消失；原生候选在实时发布前也会被移除。

修改后：

- 可信位姿继续更新正式绿色轨迹。
- 0.5 秒级有效 IMU 预测转换到左相机并持续移动相机轴，使用独立橙色临时轨迹。
- 原生候选使用独立黄色参考轨迹，明确标记“尚未验证”。
- 预测超过 2 秒、IMU 缺口或候选非法时冻结最后相机轴并显示年龄。
- 视觉恢复时切回可信位姿，允许位置跳变；预测轨迹不与可信轨迹连线。
- 新地图或新局部段不会继承旧显示状态。
- 客户 GUI 和研发 GUI 共用 `VioPanel` 与同一个选择器。
